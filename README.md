# GUVI Full Stack User Management System

## Overview

A Full Stack User Management Application developed using PHP, MySQL, MongoDB, Redis, AJAX, Bootstrap and jQuery.

## Features

- User Registration
- User Login Authentication
- Session Management using Redis
- User Profile Management
- MongoDB Profile Storage
- AJAX Based Communication
- Responsive UI Design
- Logout Functionality

## Tech Stack

### Frontend
- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery

### Backend
- PHP

### Databases
- MySQL
- MongoDB
- Redis
